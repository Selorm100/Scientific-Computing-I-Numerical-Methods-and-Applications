# Scientific-Computing-I-Numerical-Methods-and-Applications
This project focuses on the implementation and application of numerical methods using Python to solve real-world mathematical problems. It includes root-finding techniques (Bisection, Secant, Newton-Raphson, and Fixed-Point Iteration), numerical solutions of ordinary differential equations using Euler’s method, and solving systems of linear equations with Gaussian elimination. The project also integrates Bash scripting and Gnuplot for automation and visualization, allowing for analysis and comparison of convergence behavior and numerical accuracy.
